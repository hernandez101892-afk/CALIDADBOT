================================================================================ # 🚀 Guía de Activación de la App Web (PWA) en GitHub Pages Para transformar tu repositorio `CALIDADBOT` en una **App Web Interactiva** funcionando 24/7 sin servidores: ### 1️⃣ Subir el archivo `index.html` a tu Repositorio 1. Descarga el código contenido en `app_web_pwa_github_pages.txt` (o copia su contenido). 2. Ve a tu repositorio en GitHub: `https://github.com/hernandez101892-afk/CALIDADBOT` 3. Haz clic en **Add file** ➔ **Create new file**. 4. Nombra el archivo exactamente: `index.html` 5. Pega el código completo y presiona **Commit changes**. --- ### 2️⃣ Activar GitHub Pages (1 Solo Clic) 1. En tu repositorio, entra a la pestaña **Settings** (Configuración superior). 2. En el menú de la izquierda, selecciona **Pages**. 3. En la sección **Build and deployment**: * **Source:** Selecciona `Deploy from a branch`. * **Branch:** Selecciona `main` y la carpeta `/ (root)`. 4. Haz clic en **Save**. --- ### 🌐 Tu URL Pública Web En menos de 1 minuto, GitHub activará tu App Web en la dirección: 👉 **`https://hernandez101892-afk.github.io/CALIDADBOT/`** --- ### 📷 ¿Dónde se guardan las Fotos y Registros? - **Fotografías:** Se guardan en la carpeta `ARCHIVOS/imagenes/` de tu repositorio de GitHub. - **Registros:** Se guardan y acumulan en `ARCHIVOS/registro_incidencias_calidad_14campos.csv`.
